# Proyecto de Manejo de Archivos en C++

Este repositorio contiene los ejercicios de clase sobre persistencia de datos.

## Contenido:
* **Archivos de Texto:** Lectura y escritura básica de archivos .txt.
* **Archivos Binarios:** Manejo de datos en formato binario (.dat).
* **Serialización:** Ejemplo de cómo guardar objetos complejos.

## Cómo probarlo:
Cada carpeta contiene su propio archivo fuente. Se recomienda compilar individualmente cada ejercicio.
